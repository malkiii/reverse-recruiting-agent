# Job Alert placeholders

The image a Job Board's Job Alert shows when its Job has no Company logo, or the logo fails to fetch. Job Feeds use a generated placehold.co image naming the host instead. Name each file after its source, as `.png`, `.jpg`, `.jpeg` or `.webp`:

- `linkedin.png`: LinkedIn Jobs
- `glassdoor.png`: Glassdoor Jobs

A missing placeholder sends the Job Alert as text.
